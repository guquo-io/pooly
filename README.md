# Pooly

Web app de gestão para piscineiros: agenda, clientes, cobranças, recibos e orçamentos em PDF, gastos e equipe.

**Status:** em uso real desde outubro de 2026.

🎬 Trailer: https://www.youtube.com/watch?v=-umEQHy-oE0

> Este repositório apresenta o projeto. O código não é público e está disponível sob pedido.

## Contexto

O Pooly foi criado para um piscineiro autônomo que organizava o trabalho pelo WhatsApp e de memória. Sem um controle de quem devia e quanto, cobranças deixavam de ser feitas. Recibos e orçamentos dependiam de outra pessoa para serem montados, o que atrasava a entrega ou fazia com que não fossem emitidos.

## Funcionalidades

- Agenda dos atendimentos.
- Cadastro de clientes.
- Cobranças, com filtro de quem está devendo e quanto.
- Recibos e orçamentos em PDF, gerados e personalizados pelo próprio usuário.
- Gastos organizados por categoria.
- Desempenho de cada funcionário.
- Backup e restauração dos dados em arquivo JSON.

## Resultado

Desde a entrega, o usuário emite recibos e orçamentos sozinho. Isso liberou cerca de 4 horas por semana que antes eram gastas montando esses documentos.

## Próximos passos

- Banco de dados na nuvem.
- Autenticação e login.
- Sistema de pagamento.
- Acesso para mais piscineiros.

## Tecnologias

- HTML, CSS e JavaScript, num arquivo só.
- Funciona no navegador do celular e pode ser adicionado à tela inicial.
- PDFs gerados no próprio aparelho, com a biblioteca jsPDF.
- Dados guardados no navegador do usuário (por enquanto, sem servidor), com backup e restauração em JSON para não perder nada ao trocar de aparelho.
- Desenvolvido com ajuda do Claude (vibe coding).
